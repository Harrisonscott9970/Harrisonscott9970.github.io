ScreenSense

A mobile digital-wellbeing app that helps students manage screen time. It combines mood check-ins, journal entries and behavioural signals to give personalised suggestions, not generic "take a break" advice.

  • TypeScript mobile frontend built with React Native & Expo
  • FastAPI backend with validation, a database and Swagger docs
  • Explainable ML: Random Forest stress model with 79.8% F1 on held-out data, plus LSTM mood trends and journal analysis
  • 37 passing pytest tests, usability-tested with real users, and safety-first stepped-care recommendations
